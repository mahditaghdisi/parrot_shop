# 🦜 پرندگان‌شاپ — فروشگاه اینترنتی پرندگان زینتی

فروشگاه اینترنتی کامل و آماده اجرا، ساخته‌شده با **Django**، برای فروش پرندگان زینتی. شامل صفحه اصلی، دسته‌بندی، جستجو و فیلتر، صفحه محصول با گالری و نظرات، سبد خرید، تسویه‌حساب، ثبت‌نام/ورود کاربر، پنل سفارش‌های من، و پنل مدیریت (ادمین) کامل.

## امکانات

- صفحه اصلی با بنر، دسته‌بندی‌ها، پیشنهاد ویژه، تخفیف‌دار‌ها و تازه‌ترین‌ها
- لیست محصولات با فیلتر (سطح نگهداری، محدوده قیمت، سخن‌گو بودن) و مرتب‌سازی
- جستجوی محصول
- صفحه اختصاصی هر پرنده: گالری تصاویر، مشخصات (گونه/جنسیت/سن/رنگ)، امتیاز و نظرات کاربران، محصولات مشابه
- سبد خرید (بر پایه سشن)، امکان تغییر تعداد و حذف
- فرآیند تسویه‌حساب با ثبت آدرس و انتخاب روش پرداخت (نقدی در محل / آنلاین)
- ثبت‌نام، ورود، خروج و صفحه «سفارش‌های من»
- پنل مدیریت جنگو برای افزودن/ویرایش دسته‌بندی‌ها، پرنده‌ها، تصاویر گالری، سفارش‌ها و نظرات
- طراحی رابط کاربری اختصاصی (سبز جنگلی + مرجانی)، راست‌به‌چپ، فونت وزیرمتن، کاملاً ریسپانسیو

## اجرای پروژه روی سیستم شما (ویندوز)

۱. پایتون (نسخه ۳.۱۱ یا بالاتر) باید نصب باشد.

۲. در پوشه پروژه، در Git Bash یا CMD:

```bash
python -m venv venv
venv\Scripts\activate      # در Git Bash: source venv/Scripts/activate
pip install -r requirements.txt
```

۳. اجرای migration ها و ساخت دیتابیس:

```bash
python manage.py migrate
```

۴. ساخت کاربر مدیر (ادمین):

```bash
python manage.py createsuperuser
```

۵. (اختیاری ولی پیشنهادی) پر کردن چند دسته‌بندی و پرنده نمونه برای تست سریع:

```bash
python manage.py seed_data
```

۶. اجرای سرور توسعه:

```bash
python manage.py runserver
```

سایت روی `http://127.0.0.1:8000/` و پنل مدیریت روی `http://127.0.0.1:8000/admin/` در دسترس است.

> این پروژه از قبل با چند دسته‌بندی، پرنده نمونه، و یک حساب ادمین آماده پر شده تا بلافاصله بتوانید سایت را ببینید:
> - نام کاربری ادمین: `admin`
> - رمز عبور: `adminpass123`
>
> پیشنهاد می‌شود بلافاصله بعد از اجرا این رمز را از پنل ادمین تغییر دهید.

## مدیریت محصولات (پرنده‌ها)

از پنل ادمین (`/admin/`):
1. ابتدا چند «دسته‌بندی» بسازید (مثلاً عروس هلندی، مرغ عشق، کاسکو...).
2. سپس در بخش «پرنده‌ها»، هر پرنده را با تصویر، قیمت، موجودی و توضیحات ثبت کنید. می‌توانید چند تصویر گالری هم برای هر پرنده اضافه کنید.

## دیپلوی روی Render — راهنمای صفر تا صد

⚠️ **نکته مهم:** روی سرویس‌های رایگان Render، دیسک سرور **موقتی (ephemeral)** است — یعنی اگر از SQLite استفاده کنید، با هر دیپلوی جدید (یا هر چند وقت یک‌بار به‌صورت خودکار) کل اطلاعات (سفارش‌ها، پرنده‌ها، کاربران) پاک می‌شود. به همین دلیل پروژه از قبل طوری تنظیم شده که وقتی متغیر محیطی `DATABASE_URL` وجود داشته باشد، خودش سراغ **PostgreSQL** می‌رود، و وقتی نباشد (روی سیستم خودتان) از SQLite استفاده می‌کند — نیازی به تغییر دستی کد نیست.

### مرحله ۱ — آپلود پروژه روی گیت‌هاب

از VS Code یا Git Bash (همان روشی که قبلاً برای سایت پدرتان استفاده کردید):
```bash
git init
git add .
git commit -m "پروژه اولیه پرندگان‌شاپ"
```
سپس یک ریپازیتوری جدید (مثلاً `parrotshop`) در گیت‌هاب بسازید و پوش کنید:
```bash
git remote add origin https://github.com/mahditaghdisi/parrotshop.git
git branch -M main
git push -u origin main
```
(فایل `db.sqlite3` و `venv/` به لطف `.gitignore` پوش نمی‌شوند — همین‌طور درست است.)

### مرحله ۲ — ساخت دیتابیس PostgreSQL در Render

1. در داشبورد Render روی **New +‎ → PostgreSQL** بزنید.
2. یک نام بدهید (مثلاً `parrotshop-db`)، نزدیک‌ترین Region را انتخاب کنید، پلن **Free** را بزنید و بسازید.
3. چند دقیقه صبر کنید تا وضعیتش `Available` شود. نیازی به کپی کردن چیزی نیست — در مرحله بعد Render خودش وصلش می‌کند.

### مرحله ۳ — ساخت Web Service

1. **New +‎ → Web Service** و ریپازیتوری `parrotshop` را انتخاب کنید.
2. تنظیمات:
   - **Runtime:** Python 3
   - **Build Command:** `./build.sh`
   - **Start Command:** `gunicorn parrotshop.wsgi:application`
   - **Instance Type:** Free

### مرحله ۴ — متغیرهای محیطی (Environment Variables)

در تب **Environment** همین سرویس، این متغیرها را اضافه کنید:

| Key | Value |
|---|---|
| `SECRET_KEY` | یک رشته تصادفی طولانی (روی Render دکمه «Generate» هم دارد) |
| `DEBUG` | `False` |
| `PYTHON_VERSION` | `3.12.0` |
| `DATABASE_URL` | از دیتابیسی که در مرحله ۲ ساختید، روی **Connect → Internal Database URL** بزنید و همان‌جا با دکمه «Add from Database» مستقیم وصلش کنید (بهتر از کپی دستی است) |

متغیر `RENDER_EXTERNAL_HOSTNAME` را **خودِ Render به‌صورت خودکار** می‌سازد و دستی لازم نیست اضافه کنید — کد پروژه از قبل آن را می‌خواند.

### مرحله ۵ — دیپلوی

روی **Create Web Service** بزنید. Render خودش `build.sh` را اجرا می‌کند که این کارها را پشت‌سرهم انجام می‌دهد:
```
pip install -r requirements.txt
python manage.py collectstatic --no-input
python manage.py migrate        ← جداول را روی PostgreSQL می‌سازد
```
در تب **Logs** می‌توانید پیشرفت را ببینید. اگر همه‌چیز سبز شد، سایت روی آدرسی شبیه `https://parrotshop.onrender.com` بالا می‌آید.

### مرحله ۶ — ساخت ادمین و دیتای نمونه

از تب **Shell** همین سرویس در داشبورد Render (یک ترمینال آنلاین به سرور خودتان می‌دهد):
```bash
python manage.py createsuperuser
python manage.py seed_data   # اختیاری — چند دسته‌بندی و پرنده نمونه اضافه می‌کند
```

### مرحله ۷ — تست نهایی

- `https://<آدرس‌شما>.onrender.com/` → باید صفحه اصلی بیاید
- `https://<آدرس‌شما>.onrender.com/admin/` → با کاربری که در مرحله ۶ ساختید وارد شوید و چند پرنده واقعی با عکس اضافه کنید

### درباره تصاویر آپلودی (مهم)

عکس‌هایی که از پنل ادمین آپلود می‌کنید هم روی دیسک موقتی Render ذخیره می‌شوند و ممکن است با ری‌استارت سرور پاک شوند. برای فعلاً و تست مشکلی ندارد، ولی برای پروداکشن واقعی بهتر است یک سرویس ذخیره‌سازی خارجی مثل **Cloudflare R2** یا **Liara Object Storage** (که در ایران هم در دسترس‌تر است) وصل شود. اگر خواستید در مرحله بعد این را هم برایتان اضافه می‌کنم.

### دامنه اختصاصی (اختیاری)

چون قبلاً با Cloudflare برای دامنه `.ir` کار کرده‌اید، همان روش اینجا هم جواب می‌دهد:
1. در Render تب **Settings → Custom Domain** دامنه‌تان را اضافه کنید و رکورد CNAME پیشنهادی را در Cloudflare بسازید.
2. چون این دامنه خودکار به `RENDER_EXTERNAL_HOSTNAME` اضافه نمی‌شود، خودتان باید دو متغیر محیطی دیگر هم در Render تنظیم کنید:
   - `ALLOWED_HOSTS` → مثلاً `parrotshop.ir,www.parrotshop.ir`
   - `CSRF_TRUSTED_ORIGINS` → مثلاً `https://parrotshop.ir,https://www.parrotshop.ir`

(هر دو متغیر از قبل در کد پشتیبانی می‌شوند، فقط کافیست مقداردهی کنید.)

## پرداخت آنلاین واقعی (گام بعدی)

در حال حاضر دو روش پرداخت وجود دارد: «پرداخت در محل» و «پرداخت آنلاین» (که فعلاً به‌صورت نمایشی سفارش را با وضعیت «در انتظار پرداخت» ثبت می‌کند). برای اتصال واقعی به درگاه (مثل زرین‌پال، آیدی‌پی یا نکست‌پی) لازم است:
1. یک حساب پذیرنده نزد یکی از درگاه‌ها بسازید و Merchant ID بگیرید.
2. یک ویو جدید برای شروع پرداخت و یک ویو callback برای تایید تراکنش اضافه شود.

اگر بخواهید، در مرحله بعد این اتصال را هم برایتان پیاده می‌کنم.

## ساختار پروژه

```
parrotshop/       تنظیمات اصلی جنگو
shop/             دسته‌بندی، محصول (پرنده)، نظرات، صفحه اصلی و لیست/جزئیات محصول
cart/             سبد خرید (بر پایه سشن)
orders/           ثبت سفارش و تاریخچه
accounts/         ثبت‌نام / ورود / پروفایل
templates/        قالب پایه (base.html) و فایل css اصلی در static/css/style.css
```
